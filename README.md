# Botium Toys Security Audit – 2025

This repository contains the results of a detailed **security controls and compliance audit** conducted for **Botium Toys**.  
The audit highlights existing security gaps and provides recommendations to strengthen the organization’s overall cybersecurity posture.

---

## 📂 Contents

- **Control Assessment**  
  Evaluation of key security controls, including:
  - Least privilege  
  - Firewalls & IDS  
  - Data encryption  
  - Logging & monitoring  

- **Compliance Review**  
  Alignment with industry standards:
  - PCI DSS  
  - GDPR  
  - SOC 1 & SOC 2  

- **Recommendations**  
  Clear and actionable steps for addressing deficiencies and reducing risks.  

---

## ⚠️ Summary of Key Issues Identified

1. Implement least privilege and enforce separation of duties  
2. Establish regular maintenance for legacy systems  
3. Encrypt sensitive data (including customer payment information)  
4. Create and test disaster recovery & incident response plans  
5. Introduce secure password policies and implement a password manager
